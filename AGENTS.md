# emprestAI — prática individual REST

Leia o PRD, os ADRs e as regras em docs/ antes de alterar código. A API NestJS/Prisma e a SPA React/Vite são repositórios independentes. A prática usa as specs 002 e 003.

- Siga docs/rules/spec-flow.md, restrictions.md, checks.md e migration.md.
- A spec aprovada decide o comportamento. O PRD e os ADRs registram as decisões duráveis.
- Execute uma tarefa por vez. O verificador independente é obrigatório no fechamento.
- Banco e Storage de produção são operados pela titular da entrega. Use apenas banco descartável para checks.
