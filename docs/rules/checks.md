# Checks locais

- Execute npm test e npm run build em cada repositório; no frontend execute também npm run lint.
- Rode integração com o PostgreSQL descartável preparado para a prática. Aplique todas as migrations Prisma antes dos testes de banco.
- Inspecione git status --short e relacione os checks ao CA. Falha, ausência ou teste pulado não é aprovação.
- Feche as specs com o verificador do backend, entregando o par exato de commits e as evidências dos dois repositórios.
